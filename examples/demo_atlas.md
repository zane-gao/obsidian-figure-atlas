# Demo Paper: A Synthetic Example for Figure Atlas

## 论文速览

- **一句话**：这是一篇虚构论文，用来展示 atlas 的图表组织方式，不包含真实论文图表。
- **作者 / Venue**：Atlas Demo Team；Synthetic Example 2026
- **方向**：research workflow / paper reading / visual evidence design
- **Source**：[repository](https://github.com/zane-gao/obsidian-figure-atlas)
- **Source confidence**：high for repository metadata; synthetic for paper content.
- **图表主线**：overview figure -> pipeline figure -> results table。

## 图表精读

### Fig. 1 - hero overview

![[assets/demo-paper/fig01_hero_overview.svg|800]]

- **证明什么**：一个好 atlas 不只是存图，而是把问题、方法、证据和复用启发串起来。
- **设置口径**：示例图使用虚构模块，模拟从 paper list 到 Obsidian note 的阅读流程。
- **图表 taste**：用从左到右的 evidence chain 降低理解成本，适合做论文方法总览或汇报开场。
- **可借鉴**：真实论文的 Fig. 1 可以优先分析它如何定义问题、承诺贡献和安排读者视线。

### Fig. 2 - method pipeline

![[assets/demo-paper/fig02_method_pipeline.svg|800]]

- **证明什么**：采集、筛选、解读、验证应该是分阶段动作，不应混在一次性截图堆叠里。
- **设置口径**：这里只展示 workflow，不代表真实模型结构或实验协议。
- **图表 taste**：把 validation 放在末端，提醒读者图表笔记也需要 provenance 和 broken-link 检查。
- **可借鉴**：写论文方法图时，可以把质量控制步骤作为显式 panel，而不是藏在正文里。
